# MacPilot

**Your Mac, at a glance. Your everyday tools, within reach.**

MacPilot is a native, local-first utility for macOS 13+. It combines a live overview, reviewed cache cleanup, timed Keep Awake sessions, Finder controls, and optional clipboard history. No accounts, telemetry, or third-party package dependencies.

## 0.2 preview

- **Overview:** CPU history, estimated memory use, available storage, battery, and shortcuts to everyday tools. Native light/dark appearance and adaptive cards.
- **Storage:** scan user cache folders, inspect them in Finder, select individual folders, and confirm before moving them to Trash. Nothing is automatically selected. Errors and partial scans are visible.
- **Quick controls:** timed Keep Awake sessions and a confirmed Finder restart when changing hidden-file visibility.
- **Clipboard:** opt in each launch, search up to 50 text items, copy or remove individual items, pause capture, and clear history. Text stays in memory.
- **Menu bar:** live CPU/memory and a one-hour Keep Awake toggle.

This is a developer preview, not a signed/notarized public release. See [the release roadmap](ROADMAP.md) for the remaining launch requirements.

## Build and run

Requires Xcode or a Command Line Tools installation with Swift 5.9 or later on macOS.

```sh
xcode-select --install  # only if developer tools are not installed
git clone https://github.com/DanielKociuba/MacPilot.git
cd MacPilot
swift test
bash build.sh
open build/MacPilot.app
```

`bash build.sh --install` replaces `/Applications/MacPilot.app` with the local build. The generated app is ad-hoc signed for development; that is not Developer ID signing or notarization. CI also builds a preview ZIP as a workflow artifact.

## Behaviors worth knowing

- Cleanup only scans direct folders in `~/Library/Caches`; symlink entries are excluded and paths are checked again before moving. Close affected apps before cleanup. Caches can include offline content, and apps may recreate them.
- Moving caches to Trash does **not** reclaim the reported size immediately. Inspect them in Finder and empty Trash yourself when ready. Some folders may be inaccessible; scan sizes may be partial.
- Clipboard history starts disabled at every launch. Concealed, transient, and autogenerated clipboard markers are respected, but apps do not consistently mark sensitive text. Pause capture before copying secrets. Text over 100 KB is skipped. Clearing history does not alter the current system clipboard.
- Keep Awake prevents idle system/display sleep. It is not a closed-lid mode. Sessions stop on expiry, stop, or app exit.
- Memory is an estimate, not macOS memory pressure. Available storage includes reclaimable capacity reported by macOS. There are no invented health scores or “RAM boost” claims.

## Source layout

`Sources/MacPilot` is the single source of truth. `CleanupService.swift` contains scan and path validation logic. `Tools.swift` manages controls and async cleanup. `SystemStats.swift` reads system counters. `ClipboardStore.swift` holds session-only history. `ContentView.swift` defines the UI.

## Validation

Run `swift test` and `bash build.sh` on macOS. Tests use isolated temporary folders and an injected move operation; they never touch real user caches or Trash. The GitHub Actions workflow runs tests, builds the bundle, verifies its ad-hoc signature, and uploads the preview.

Before a public release, also complete the manual checks in [ROADMAP.md](ROADMAP.md). CI cannot establish that the interface looks right, that permissions behave well on a clean Mac, or that the utility stays lightweight under real workloads.
